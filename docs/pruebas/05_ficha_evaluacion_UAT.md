# Ficha de evaluación de aceptación con trabajadores

Estado del documento: **plantilla preparada, sin resultados de trabajadores**.

Usar con [la guía de recorridos](04_aceptacion_UAT.md). Copiar esta ficha por participante y repetir el detalle por cada escenario realizado. Guardar las fichas completadas en un lugar privado acordado con la empresa; no publicar nombres, firmas, credenciales ni datos reales en GitHub. Para un informe público usar códigos de participante.
